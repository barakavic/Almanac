# v0.1.1 — Storage & Permission Fixes

**Released:** September 2026  
**Build:** `0.1.1+1`  
**Platform:** Android

---

## Overview

This patch release addresses the Android storage and permission issues discovered during device pairing and remote book transfer testing. It hardens the download flow, adds startup permission prompts, and avoids crashes when a user chooses a public or non-writable phone folder.

---

## Highlights

### Android permission flow
- Request camera and storage permissions at initial app startup
- Re-check permissions when a user attempts to open a QR scanner or a storage-sensitive action
- Display a clear dialog when permission is denied or missing

### Transfer reliability
- Validate whether the selected destination folder is writable
- Fallback to a safe app-owned library directory when the external path is blocked
- Replace the generic transfer error path with a user-readable failure dialog
- Prevent `PathAccessException` for public phone directories that the app cannot write to

### Pairing and device UX
- Preserve the QR and PIN pairing flows while keeping permission prompts explicit and non-intrusive
- Reduce confusion by explaining to the user that a public phone folder is not guaranteed to be writable under Android scoped storage rules

---

## Bug Fixes

- Fixed `PathAccessException` during remote downloads when the selected target folder was not writable
- Fixed silent transfer failure caused by writing into inaccessible shared storage paths
- Fixed the app-level permission model by moving key permission requests into startup flow rather than waiting until the feature is tapped
- Fixed inconsistent permission UX when the camera was used only from the pairing dialog

---

## Notes

If the user specifically wants to save into a public shared folder on the phone, Android may still require explicit permission and may reject writes depending on the OS version and folder scope. When that is not allowed, the app now falls back to a safe app-managed storage path to keep transfers reliable.
